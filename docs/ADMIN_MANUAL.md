# Manual administrativo · Borrador de referencia

En la copia auditada, acceder a /admin/login con una cuenta autorizada abre /admin/dashboard. El menú presenta productos, categorías, pedidos, reseñas y configuración. Estas seis pantallas se abrieron con sesión sintética. Las rutas de alta permitieron crear una categoría y un producto sintéticos y encontrarlos mediante filtro. En productos y categorías hay formularios de edición; configuración agrupa textos, destinos y medios. El detalle de pedido redirige al listado y los cambios de estado necesitan controles adicionales.

El manual de entrega requerirá capturas del sistema aprobado, procedimientos de stock, plantillas y aprobación, cobro y reembolso, logística, clientes, reseñas, integraciones, roles y recuperación. Validar mediante T26 con el operador. Documento de control F0, pendiente de UAT y PDF final.
